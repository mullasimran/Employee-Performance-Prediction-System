# Employee Performance Prediction System

## Overview
The Employee Performance Prediction System is a Machine Learning based web application that predicts employee performance using various employee-related factors such as department, job title, experience, work mode, salary, and performance rating.
The system helps organizations analyze employee performance and maintain prediction records for reporting and decision-making purposes.

## Features
* Employee Performance Prediction
* Machine Learning Model Integration
* Prediction History Management
* Reports Dashboard
* Admin Dashboard
* CSV Data Export
* Responsive User Interface
* SQLite Database Storage

## How to Run
1. Install Python
2. Install required libraries:
   pip install -r requirements.txt
3. Run the application:
   python app.py
4. Open browser:
   http://127.0.0.1:5000
